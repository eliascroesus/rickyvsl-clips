# Thank-you video: raw footage

Ricky's raw recording for the thank-you video goes here (the one that gets edited to match
[`thank-you-vsl-reference`](../thank-you-vsl-reference)).

- **The video itself (up to 2 GB):** use the
  [Thank-you raw footage release](https://github.com/eliascroesus/rickyvsl-clips/releases/new?tag=thank-you-raw-footage&title=Thank-you%20raw%20footage)
  (if GitHub asks about the tag, pick **Create new tag … on publish**), drag the video into the box at the bottom,
  wait until it has finished uploading, then click **Publish release**.
- **Small files (under 25 MB)**, e.g. a script or extra clips/pictures for it:
  [upload to this folder](https://github.com/eliascroesus/rickyvsl-clips/upload/claude/nice-rubin-bayjpu/thank-you-raw-footage).
